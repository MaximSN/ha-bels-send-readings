# БЭЛС — Home Assistant integration

Интеграция Home Assistant для передачи показаний электросчётчика в БЭЛС.

## Возможности

- Редактирование показаний непосредственно в карточке перед отправкой.
- Округление показаний вверх до заданной кратности.
- Ручная и автоматическая отправка показаний в API БЭЛС.
- История отправок показаний

## Установка

Установите репозиторий как custom integration через HACS или MarketPlace (Custom repositories, category Integration) либо скопируйте \`custom_components/bels\` в каталог \`config/custom_components/bels\`.

После установки перезапустите Home Assistant и добавьте интеграцию **БЭЛС — передача показаний** через Settings → Devices & services → Add integration.

После загрузки интеграции ресурс карточки регистрируется автоматически, если Lovelace использует режим Storage. Если используется YAML-режим ресурсов, добавьте в раздел \`lovelace:\` файл ресурсов вручную:

\`\`\`yaml
lovelace:
  resources:
    - url: /bels/bels-panel.js
      type: module
\`\`\`

Добавьте карточку на панель вручную в режиме YAML:

\`\`\`yaml
type: custom:bels-panel
\`\`\`

## Настройка

Лицевой счёт обязателен, телефон и e-mail необязательны. В настройках интеграции выберите сенсор «Общие (день)»; по умолчанию используется \`sensor.elektroenergiia\`. Сенсоры «Ночь» и «Пик» необязательны. Установите «Округлять вверх до кратности» в нужное значение; значение \`0\` отключает округление.

В тех же настройках доступна автоматическая отправка: её можно включить, задать день месяца (с 1-го по 31-е) и время. Если в конкретном месяце выбранного дня нет, отправка выполняется в последний день этого месяца. Настройки применяются после перезагрузки интеграции, которая выполняется автоматически при сохранении опций.

## Сервис

Сервис \`bels.submit_readings\` можно использовать в автоматизациях. Если значения не переданы, интеграция считывает выбранные сенсоры и применяет округление:

\`\`\`yaml
action: bels.submit_readings
\`\`\`

Для ручной передачи значений можно указать поля \`date\`, \`day\`, \`night\` и \`peak\`. Дата задаётся в формате \`YYYY-MM-DD\`. Поле \`day\` обязательно при ручной передаче; пустые \`night\` и \`peak\` не отправляются. Округление из настроек применяется и к значениям, переданным вручную.

## История

История отправок хранится в Store Home Assistant и доступна карточке напрямую через WebSocket API интеграции. Отдельные сущности \`sensor.bels_history\` и \`sensor.bels_last_submission\` больше не создаются.

При обновлении с версии 0.1.0 история из прежнего хранилища сохраняется.

## Безопасность

Не добавляйте в репозиторий персональные данные, cookie, реальные ответы сервера или историю отправок. Настройки и история хранятся в хранилище Home Assistant на конкретном устройстве.
