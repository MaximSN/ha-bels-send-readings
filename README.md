# БЭЛС — Home Assistant integration

Интеграция Home Assistant для передачи показаний электросчётчика в БЭЛС.

## Возможности

- Ручная и автоматическая отправка показаний в [БЭЛС](https://www.belssb.ru/).
- Округление показаний вверх до заданной кратности.
- Просмотр истории отправок показаний.

## Установка

Установите репозиторий как custom integration через HACS или Marketplace (Custom repositories, category Integration) либо скопируйте `custom_components/bels` в каталог `config/custom_components/bels`.

После установки перезапустите Home Assistant и добавьте интеграцию **БЭЛС — передача показаний** через Settings → Devices & services → Add integration.

После загрузки интеграции ресурс карточки регистрируется автоматически, если Lovelace использует режим Storage. Если используется YAML-режим ресурсов, добавьте в раздел `lovelace:` файл ресурсов вручную:

```yaml
lovelace:
  resources:
    - url: /bels/bels-panel.js
      type: module
```

Добавьте карточку на панель вручную в режиме YAML:

```yaml
type: custom:bels-panel
```

## Настройка

Заполните значение «Лицевой счёт» значением из квитанции.

Заполнение полей «Телефон» и «E-mail» необязательно.

Выберите сенсоры, возвращающие числовое значение для отправки.

Обязательно необходимо указать сенсор для «День».

Сенсоры для «Ночь» и «Пик» необязательны.

При необходимости установите «Округлять вверх до кратности» в нужное значение. Значение `0` отключает округление.

Для автоматической отправки показаний можно включить соответствующую настройку и задать расписание: день месяца (с 1-го по 31-е) и время. Если в конкретном месяце выбранного дня нет, отправка выполняется в последний день этого месяца.

## Сервис

Сервис `bels.submit_readings` можно использовать в автоматизациях. Если значения не переданы, интеграция считывает выбранные сенсоры и применяет округление:

```yaml
action: bels.submit_readings
```

Для ручной передачи значений можно указать поля `date`, `day`, `night` и `peak`. Дата задаётся в формате `YYYY-MM-DD`. Поле `day` обязательно при ручной передаче; пустые `night` и `peak` не отправляются. Округление из настроек применяется и к значениям, переданным вручную.
